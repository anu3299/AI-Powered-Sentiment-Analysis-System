# AI-Powered Sentiment Analysis System

## Project Overview

The AI-Powered Sentiment Analysis System is a machine learning project that analyzes customer reviews and classifies them into three categories: Positive, Negative, and Neutral.

The project uses Natural Language Processing (NLP) and machine learning techniques to understand customer opinions and support better decision-making.

## Objectives

* Analyze customer reviews automatically.
* Classify reviews into Positive, Negative, and Neutral sentiments.
* Apply machine learning to text data.
* Provide a simple interface for sentiment prediction.

## Technologies Used

* Python
* Pandas
* Scikit-learn
* TF-IDF Vectorization
* Multinomial Naive Bayes
* Streamlit
* Jupyter Notebook

## Project Workflow

1. Collect the customer review dataset.
2. Clean and preprocess the text data.
3. Convert text into numerical features using TF-IDF.
4. Train and evaluate machine learning models.
5. Save the trained model.
6. Predict sentiment through a Streamlit web application.

## Sentiment Categories

* **Positive:** The customer expresses satisfaction.
* **Negative:** The customer expresses dissatisfaction.
* **Neutral:** The review expresses neither clearly positive nor negative sentiment.

## How to Run the Project

Install the required libraries:

```bash
pip install -r requirements.txt
```

Run the Streamlit application from the project directory:

```bash
python -m streamlit run app.py
```
